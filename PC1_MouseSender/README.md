# PWNZ VISION PRO (UDP ULTIMATE) - PC1 Mouse Click Sender

Графическое приложение для отправки событий нажатия мыши на второй ПК через UDP.

## Требования

- Windows 10/11
- Visual Studio 2019 или новее (с компонентом C++)
- Dear ImGui (библиотека должна быть установлена в системе)
- DirectX 11

## Структура проекта

```
PC1_MouseSender/
├── main.cpp              # Основной файл с GUI и логикой
├── README.md             # Этот файл
└── build.bat             # Скрипт для быстрой компиляции
```

## Компиляция

### Вариант 1: Использование Visual Studio Developer Command Prompt

1. Откройте **Developer Command Prompt for VS**
2. Перейдите в папку проекта:
   ```cmd
   cd path\to\PC1_MouseSender
   ```
3. Скомпилируйте проект:
   ```cmd
   cl /EHsc main.cpp imgui_impl_dx11.cpp imgui_impl_win32.cpp d3d11.lib user32.lib ws2_32.lib /Fe:PWNZ_Vision_Pro.exe
   ```

### Вариант 2: Использование скрипта build.bat

Просто запустите:
```cmd
build.bat
```

### Вариант 3: Visual Studio IDE

1. Создайте новый проект **Console App** или **Windows Desktop Application**
2. Добавьте файл `main.cpp` в проект
3. Подключите файлы Dear ImGui (`imgui.h`, `imgui_impl_dx11.h/cpp`, `imgui_impl_win32.h/cpp`)
4. В свойствах проекта добавьте библиотеки:
   - `d3d11.lib`
   - `user32.lib`
   - `ws2_32.lib`
5. Соберите проект (Ctrl+Shift+B)

## Использование

### Настройка на ПК1 (Игровой компьютер)

1. Запустите `PWNZ_Vision_Pro.exe`
2. Перейдите на вкладку **NETWORK** (открывается по умолчанию)
3. В секции **TARGET MACHINE SETUP**:
   - Введите IP-адрес второго ПК (например, `192.168.1.55`)
   - Укажите порт (по умолчанию `5556` или `8080`)
4. Нажмите кнопку **[🔗 CONNECT]**
5. Статус изменится на **CONNECTED**

### Настройка на ПК2 (Компьютер с читом)

1. В GUI чита перейдите в раздел **Hardware / 2PC**
2. Включите опцию **Enable UDP Transfer**
3. Убедитесь, что порт совпадает с указанным на ПК1
4. Теперь все нажатия мыши с ПК1 будут передаваться на ПК2

## Функции GUI

### Вкладка NETWORK

- **LOCAL SYSTEM INFO**: Отображает ваш текущий IP и имя компьютера
- **TARGET MACHINE SETUP**: Поля для ввода IP и порта целевого ПК
- **Autoconnect**: Автоматическое подключение при запуске
- **Debug Mode**: Режим отладки для расширенного логирования
- **Таблица соединений**: Отображение активных подключений
- **Строка состояния**: Текущий статус соединения

### Другие вкладки

- **SYSTEM**: Системные настройки (заглушка)
- **SETTINGS**: Дополнительные настройки (заглушка)
- **LOGS**: Журнал событий подключения/отключения
- **ABOUT**: Информация о программе

## Протокол передачи данных

Приложение отправляет UDP-пакеты со следующей структурой:

| Байты | Описание |
|-------|----------|
| 0     | Тип события (0x01-0x0C) |
| 1-3   | Зарезервировано |
| 4-7   | Данные (значение колеса, флаг нажатия и т.д.) |

### Типы событий

- `0x01` - ЛКМ нажата
- `0x02` - ЛКМ отпущена
- `0x03` - ПКМ нажата
- `0x04` - ПКМ отпущена
- `0x05` - СКМ (колесо) нажато
- `0x06` - СКМ отпущено
- `0x07` - Колесо вверх
- `0x08` - Колесо вниз
- `0x09` - Боковая кнопка X1 нажата
- `0x0A` - Боковая кнопка X1 отпущена
- `0x0B` - Боковая кнопка X2 нажата
- `0x0C` - Боковая кнопка X2 отпущена

## Устранение неполадок

### Ошибка компиляции "Cannot find imgui headers"

Убедитесь, что файлы Dear ImGui находятся в пути поиска компилятора или укажите полный путь:
```cmd
cl /EHsc main.cpp C:\path\to\imgui\imgui_impl_dx11.cpp C:\path\to\imgui\imgui_impl_win32.cpp ...
```

### Приложение не подключается

1. Проверьте, что оба ПК в одной сети
2. Убедитесь, что брандмауэр не блокирует UDP-порт
3. Проверьте правильность IP-адреса
4. Убедитесь, что на ПК2 запущен сервер приема

###GUI не отображается корректно

Убедитесь, что установлены драйверы DirectX 11 и поддерживается видеокарта.
