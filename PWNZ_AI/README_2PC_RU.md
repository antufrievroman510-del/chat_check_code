## 🎮 ИНСТРУКЦИЯ ПО ЗАПУСКУ

### ШАГ 1: Настройка сети

#### На ПК2 (читовый ПК):
1. Назначьте статический IP адрес (например, `192.168.1.100`)
2. Откройте порт 5556 UDP в брандмауэре:

```powershell
netsh advfirewall firewall add rule name="PWNZ Click Server" dir=in action=allow protocol=UDP localport=5556
```

#### На обоих ПК:
- Убедитесь что оба подключены к одной WiFi сети
- Проверьте соединение: `ping 192.168.1.100`

---

### ШАГ 2: Компиляция программы для ПК1

На ПК1 (игровой) скомпилируйте `MouseClickSender.exe`:

**Visual Studio / MSVC:**
```cmd
cl /EHsc MouseClickSender.cpp Ws2_32.lib /Fe:MouseClickSender.exe
```

**MinGW:**
```cmd
g++ MouseClickSender.cpp -o MouseClickSender.exe -lws2_32 -static
```

---

### ШАГ 3: Запуск

#### На ПК1 (игровой):
1. Запустите `MouseClickSender.exe`
2. Введите IP адрес ПК2 (например, `192.168.1.100`)
3. Программа начнет перехватывать нажатия ЛКМ/ПКМ

#### На ПК2 (читовый):
1. Запустите чит как обычно
2. Сервер кликов автоматически запустится при старте чита
3. Вы увидите в консоли: `[INIT] Click server running on port 5556`

## 🔍 Как это работает

```
ПК1 (Игровой)                          ПК2 (Чит)
─────────────────                      ────────────────
Физическая мышь                        
     │                                 
     ├─→ Makcu плата ─USB────────► MakcuInput (движения)
     │                               
     └─→ MouseClickSender ─UDP──► MouseClickServer
         (перехват кликов)   5556    (в чите)
                                      │
                                      ▼
                               SendInput (эмуляция)
                                      │
                                      ▼
                               Аимбот реагирует
```

### Разделение ответственности:
- **Движения мыши** → Makcu плата (COM-порт) → аимбот рассчитывает новую позицию
- **Нажатия кнопок** → Сеть UDP 5556 → эмуляция через SendInput

## ⚙️ Настройки

### Изменение порта:
По умолчанию используется порт **5556**. Чтобы изменить:

1. В `MouseClickSender.cpp` измените порт при запуске
2. В `main.cpp` найдите `Initialize2PCClicks()` и измените `g_clickServer.start(5556)` на другой порт

### Автопереподключение:
`MouseClickSender.exe` автоматически пытается переподключиться каждые 2 секунды если соединение потеряно.

## ❓ Частые проблемы

### "Cannot connect to ..."
**Решение:**
1. Проверьте что ПК2 имеет статический IP
2. Убедитесь что порт 5556 открыт в брандмауэре ПК2
3. Проверьте что оба ПК в одной сети: `ping 192.168.1.100`

### Клики не эмулируются на ПК2
**Решение:**
1. Проверьте что чит запущен от имени администратора
2. Убедитесь что `MouseController` инициализирован
3. Проверьте логи на наличие ошибок

### Большая задержка
**Решение:**
1. Используйте WiFi 5GHz вместо 2.4GHz
2. Убедитесь что нет других устройств нагружающих сеть
3. Проверьте пинг: `ping 192.168.1.100 -t` (должен быть < 5ms в локальной сети)
