# 📖 2PC UDP CLICK TRANSFER - ПОЛНАЯ ИНСТРУКЦИЯ

## ✅ ЧТО УЖЕ РАБОТАЕТ В ЧИТЕ

### 1. Автоматическое определение IP
- Вкладка **Hardware → 2PC** показывает IP вашего читового ПК автоматически
- Поле **"Этот ПК IP (для клиента)"** заполняется само при открытии вкладки
- Этот IP нужно ввести в программу на игровом ПК

### 2. Прием UDP пакетов с нажатиями мыши
- Чит слушает UDP порт **5556** (по умолчанию)
- Принимает пакеты от MouseClickSender.exe с игрового ПК
- Распознает нажатия: **ЛКМ, ПКМ, СКМ, Колесо, X1/X2**
- При получении ПКМ → устанавливает `g_remote_aim_key = true` → **АИМБОТ АКТИВЕН**
- При получении ЛКМ → эмулирует клик через SendInput → **СТРЕЛЬБА**

### 3. GUI Панель управления
- **Enable UDP Receiver** - включение/выключение приема
- **APPLY / ПРИНЯТЬ** - сохранить настройки и перезапустить сервер
- **Статус сервера** - ✓ Сервер запущен / ⚠ Сервер остановлен
- **Индикатор кликов** - показывает последний клик (ЛКМ/ПКМ) и время
- **📖 Быстрая инструкция** - пошаговая настройка прямо в интерфейсе

## 🔧 КАК НАСТРОИТЬ (5 ШАГОВ)

### Шаг 1: На читовом ПК (ПК2)
1. Запустить **PWNZ_AI.exe**
2. Открыть меню → вкладка **Hardware**
3. Найти секцию **"2PC Mouse Click UDP"**
4. Скопировать IP из поля **"Этот ПК IP (для клиента)"** (например, `192.168.1.50`)

### Шаг 2: На игровом ПК (ПК1)
1. Запустить **MouseClickSender.exe**
2. Ввести IP читового ПК (который скопировали в Шаге 1)
3. Ввести порт (по умолчанию **5556**)
4. Нажать Enter

### Шаг 3: На читовом ПК (ПК2)
1. В том же разделе **2PC Mouse Click UDP**
2. Нажать кнопку **"APPLY / ПРИНЯТЬ"**
3. Проверить статус: должен быть **"✓ Сервер запущен"**

### Шаг 4: Проверка связи
1. На игровом ПК нажать **ПКМ** (правая кнопка мыши)
2. На читовом ПК в GUI увидеть: **"◉ ПКМ (0.X сек назад) - АИМ АКТИВЕН"**
3. В консоли чита должно появиться: `[CLICK] RMB PRESSED (from network) - AIMBOT ACTIVATED`

### Шаг 5: Настройка брандмауэра (если нужно)
На читовом ПК открыть PowerShell от администратора и выполнить:
```powershell
New-NetFirewallRule -DisplayName "PWNZ AI UDP 5556" -Direction Inbound -Protocol UDP -LocalPort 5556 -Action Allow
```


### Типы пакетов
| Байт 0 | Событие | Действие в чите |
|--------|---------|-----------------|
| 0x01 | ЛКМ Нажата | Press LMB + Индикатор |
| 0x02 | ЛКМ Отпущена | Release LMB |
| 0x03 | ПКМ Нажата | Press RMB + **g_remote_aim_key=true** |
| 0x04 | ПКМ Отпущена | Release RMB + g_remote_aim_key=false |
| 0x05 | СКМ Нажата | Press MMB |
| 0x06 | СКМ Отпущена | Release MMB |
| 0x07 | Колесо Вверх | Scroll +120 |
| 0x08 | Колесо Вниз | Scroll -120 |
| 0x09 | X1 Нажата | Press XBUTTON1 |
| 0x0A | X1 Отпущена | Release XBUTTON1 |
| 0x0B | X2 Нажата | Press XBUTTON2 |
| 0x0C | X2 Отпущена | Release XBUTTON2 |

## ⚠️ ВАЖНЫЕ ЗАМЕЧАНИЯ

1. **Сервер слушает все интерфейсы** (INADDR_ANY) - не нужно указывать IP сервера
2. **Порт 5556** должен быть открыт в брандмауэре читового ПК
3. **ПКМ активирует аимбот** через глобальный флаг `g_remote_aim_key`
4. **ЛКМ активирует стрельбу** через эмуляцию SendInput
5. **Движения мыши** обрабатываются отдельно через Makcu (COM-порт)
6. Оба ПК должны быть в **одной локальной сети**

## 🧪 ТЕСТОВАНИЕ

### Проверка на читовом ПК:
1. Открыть консоль (если видна)
2. Нажать APPLY в GUI
3. Должно появиться: `[MouseClickServer] Started successfully on port 5556`

### Проверка на игровом ПК:
1. Запустить MouseClickSender.exe
2. Ввести IP читового ПК
3. Должно появиться: `[OK] Connected to 192.168.x.x:5556`

### Проверка активации аимбота:
1. Навести прицел на врага в игре
2. Нажать ПКМ на игровом ПК
3. На читовом ПК: **"◉ ПКМ (X.X сек назад) - АИМ АКТИВЕН"**
4. Аимбот должен начать вести прицел в голову врага

## ❓ ВОЗМОЖНЫЕ ПРОБЛЕМЫ

| Проблема | Решение |
|----------|---------|
| "Сервер не запускается" | Проверить, не занят ли порт 5556 другой программой |
| "Не видит IP" | Убедиться, что ПК в одной сети, проверить ping |
| "Клики не приходят" | Отключить брандмауэр или добавить правило |
| "Аимбот не работает" | Проверить, что g_remote_aim_key меняется (индикатор в GUI) |
| "Ошибка компиляции" | Убедиться, что все extern объявления в overlay.h |
