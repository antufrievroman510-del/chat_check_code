## 📋 Как Настроить и Использовать

### Шаг 1: На Читовом ПК (Второй ПК)
1. Запусти `PWNZ_AI.exe`
2. Открой вкладку **Hardware → 2PC**
3. Найди панель **"2PC Mouse Click UDP"**
4. Скопируй IP из поля **"Этот ПК IP (для клиента):"** (например, `192.168.1.100`)
5. Нажми кнопку **"APPLY / ПРИНЯТЬ"**
6. Убедись, что статус: **"✓ Сервер запущен"**

### Шаг 2: На Игровом ПК (Первый ПК)
1. Запусти `MouseClickSender.exe`
2. В настройках укажи:
   - **IP адрес:** IP читового ПК (из шага 1)
   - **Порт:** 5556 (по умолчанию)
3. Нажми **"Start"**

### Шаг 3: Проверка Работы
1. На игровом ПК нажми **ПКМ** (прицеливание)
2. На читовом ПК в GUI увидишь:
   - `"◉ ПКМ (X.X сек назад) - АИМ АКТИВЕН"` (зелёным цветом)
3. Наведи перекрестие на врага — аимбот должен сработать
4. Отпусти ПКМ — аимбот деактивируется

## 🛡️ Требования к Брандмауэру

На **читовом ПК** должно быть разрешено:
- **Входящее UDP соединение** на порт **5556**
- Протокол: `UDP`
- Приложение: `PWNZ_AI.exe`

Команда PowerShell для добавления правила:
```powershell
New-NetFirewallRule -DisplayName "PWNZ AI UDP 5556" -Direction Inbound -Protocol UDP -LocalPort 5556 -Action Allow
```

## 🐛 Отладка

Если клики не принимаются:

1. **Проверь консоль чита** (stdout):
   - Должно быть: `[MouseClickServer] Started successfully on port 5556`
   - При клике: `[CLICK] RMB PRESSED (from network) - AIMBOT ACTIVATED`

2. **Проверь GUI индикатор**:
   - Должен показывать время последнего клика (< 3 сек)

3. **Проверь брандмауэр**:
   ```powershell
   Get-NetFirewallRule | Where-Object { $_.DisplayName -like "*5556*" }
   ```

4. **Проверь подключение** (на игровом ПК):
   ```powershell
   Test-NetConnection -ComputerName <IP_читового_ПК> -Port 5556
   ```
