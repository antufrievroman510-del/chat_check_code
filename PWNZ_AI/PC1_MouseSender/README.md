# PWNZ VISION PRO (UDP ULTIMATE) - PC1 Mouse Sender

## Описание
Приложение для отправки событий нажатия мыши с ПК1 на ПК2 через UDP протокол. Использует графический интерфейс на базе Dear ImGui.

## Требования
- Windows 10/11
- Visual Studio 2019 или новее (с компонентом "Desktop development with C++")
- CMake 3.15 или новее
- DirectX 9 SDK (входит в состав Windows SDK)

## Структура проекта
```
PC1_MouseSender/
├── CMakeLists.txt          # Файл конфигурации CMake
├── src/
│   └── main.cpp            # Исходный код приложения
├── imgui_lib/              # Библиотека Dear ImGui (уже включена)
└── README.md               # Этот файл
```

## Сборка с помощью CMake

### Вариант 1: Командная строка (Visual Studio Developer Command Prompt)

1. Откройте **Developer Command Prompt for VS** (или PowerShell с настроенным окружением MSVC)
2. Перейдите в папку проекта:
   ```bash
   cd PWNZ_AI/PC1_MouseSender
   ```
3. Создайте директорию для сборки и выполните конфигурацию:
   ```bash
   mkdir build
   cd build
   cmake .. -G "Visual Studio 16 2019" -A x64
   ```
   
   Или для Visual Studio 2022:
   ```bash
   cmake .. -G "Visual Studio 17 2022" -A x64
   ```

4. Соберите проект:
   ```bash
   cmake --build . --config Release
   ```

5. Готовый исполняемый файл будет находиться в: `build/bin/PWNZ_Vision_Pro.exe`

### Вариант 2: Visual Studio IDE

1. Откройте Visual Studio
2. Выберите **File → Open → Folder** и укажите папку `PWNZ_AI/PC1_MouseSender`
3. Visual Studio автоматически распознает `CMakeLists.txt`
4. В верхней панели выберите конфигурацию **Release** и платформу **x64**
5. Нажмите **Build → Build All** (или Ctrl+Shift+B)
6. Исполняемый файл появится в папке `out/build/x64-Release/bin/`

### Вариант 3: CMake GUI

1. Запустите **CMake GUI**
2. В поле "Where is the source code" укажите путь к `PWNZ_AI/PC1_MouseSender`
3. В поле "Where to build the binaries" укажите новую папку, например `PWNZ_AI/PC1_MouseSender/build`
4. Нажмите **Configure**
5. Выберите генератор: **Visual Studio 16 2019** или **Visual Studio 17 2022**, платформа **x64**
6. Нажмите **Finish**, дождитесь завершения конфигурации
7. Нажмите **Generate**
8. Откройте созданный файл `PWNZ_Vision_Pro.sln` в Visual Studio и соберите проект

## Использование

### На ПК1 (Игровой компьютер - отправитель)

1. Запустите `PWNZ_Vision_Pro.exe`
2. Перейдите на вкладку **NETWORK** (открывается по умолчанию)
3. В разделе **TARGET MACHINE SETUP**:
   - Введите IP-адрес второго ПК в поле **Remote IP (Target PC)** (например, `192.168.1.55`)
   - Укажите порт в поле **Port** (по умолчанию `5556`)
4. Нажмите кнопку **[🔗 CONNECT]**
5. Статус изменится на **CONNECTED - Sending mouse clicks to ...**
6. Теперь все нажатия мыши (ЛКМ, ПКМ, СКМ, колесо, боковые кнопки X1/X2) будут передаваться на ПК2

### На ПК2 (Компьютер с читом - получатель)

1. В меню чита перейдите в раздел **Hardware / 2PC**
2. Включите опцию **Enable UDP Transfer**
3. Убедитесь, что порт совпадает с указанным в приложении на ПК1 (по умолчанию `5556`)
4. Чит начнет получать и обрабатывать события мыши

## Протокол обмена данными

Приложение использует UDP пакеты следующего формата:

| Байты | Описание |
|-------|----------|
| 0     | Тип события (0x01-0x0C) |
| 1-3   | Зарезервировано |
| 4-7   | Дополнительные данные (значение колеса и т.д.) |

Типы событий:
- `0x01` - ЛКМ нажата
- `0x02` - ЛКМ отпущена
- `0x03` - ПКМ нажата
- `0x04` - ПКМ отпущена
- `0x05` - СКМ нажата
- `0x06` - СКМ отпущена
- `0x07` - Колесо вверх
- `0x08` - Колесо вниз
- `0x09` - Боковая кнопка X1 нажата
- `0x0A` - Боковая кнопка X1 отпущена
- `0x0B` - Боковая кнопка X2 нажата
- `0x0C` - Боковая кнопка X2 отпущена

## Настройки интерфейса

- **Autoconnect**: Автоматическое подключение при запуске (планируется)
- **Debug Mode**: Режим отладки с подробным логированием (планируется)

## Устранение неполадок

### Ошибка компиляции "Cannot find imgui.h"
Убедитесь, что папка `imgui_lib` существует и содержит файлы библиотеки. Если нет, клонируйте репозиторий:
```bash
git clone --depth 1 https://github.com/ocornut/imgui.git imgui_lib
```

### Ошибка "Direct3D device creation failed"
- Убедитесь, что установлены компоненты DirectX
- Попробуйте запустить от имени администратора
- Проверьте, что видеокарта поддерживает DirectX 9

### Соединение не устанавливается
1. Проверьте, что оба ПК находятся в одной сети
2. Убедитесь, что брандмауэр Windows не блокирует порт (разрешите приложение в брандмауэре)
3. Проверьте правильность IP-адреса и порта
4. На ПК2 убедитесь, что UDP-сервер запущен и слушает указанный порт

### Как узнать IP-адрес ПК2?
На ПК2 откройте командную строку и введите:
```bash
ipconfig
```
Найдите адрес в разделе "Ethernet adapter" или "Wireless LAN adapter" (обычно начинается с `192.168.` или `10.`)
