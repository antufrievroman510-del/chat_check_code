# 🖱️ 2PC Mouse Click Setup - Инструкция

## 📁 Структура файлов

```
PWNZ_AI/
├── PC1_MouseSender/          # Папка для ПЕРВОГО ПК (игровой)
│   ├── MouseSender.cpp       # Исходный код отправителя кликов
│   ├── config.txt            # Конфигурация (IP и порт)
│   ├── build.bat             # Скрипт компиляции
│   └── README_RU.txt         # Подробная инструкция
│
├── MouseClickServer.h        # Сервер кликов (встроен в чит на ПК2)
├── MouseController.h/cpp     # Контроллер мыши (уже в чите)
└── main.cpp                  # Главный файл чита (уже интегрировано)
```

---

## 🚀 Быстрый старт

### ПК1 (Игровой) - Отправитель кликов

1. **Скомпилируйте программу:**
   ```cmd
   cd C:\PWNZ AI\PC1_MouseSender
   build.bat
   ```

2. **Настройте IP:**
   - Откройте `config.txt`
   - Замените `IP=192.168.1.100` на IP второго ПК

3. **Запустите от имени администратора:**
   ```cmd
   MouseSender.exe
   ```

---

### ПК2 (Читовый) - Приемник кликов

1. **Откройте порт в брандмауэре:**
   ```cmd
   netsh advfirewall firewall add rule name="PWNZ AI Clicks" dir=in action=allow protocol=UDP localport=5556
   ```

2. **Запустите чит** - сервер кликов запустится автоматически

---

## ✅ Проверка работы

1. На ПК1 запустите `MouseSender.exe`
2. Нажмите ЛКМ/ПКМ
3. В консоли ПК1 увидите: `[CLICK] ЛКМ НАЖАТА`
4. Чит на ПК2 эмулирует нажатие через `MouseController`

---

## 🔧 Как это работает

```
ПК1 (Игровой)                    ПК2 (Чит)
─────────────                    ───────────
Физ. мышь → Makcu плата ─USB→   MakcuInput (движения)
     │
     └→ MouseSender ─UDP:5556→  MouseClickServer
        (перехват кликов)        (прием кликов)
                                   ↓
                            MouseController
                                   ↓
                            SendInput (эмуляция)
```

---

## 🛡️ Безопасность

- ✅ Программа на ПК1 - отдельный процесс, не внедряется в игру
- ✅ Античит не видит связь между игрой и программой
- ✅ Сеть идет от процесса чита, а не от игры
- ✅ Makcu для движений, сеть только для кликов

---

## 📝 Примечания

- Порт по умолчанию: **5556** (UDP)
- Формат пакета: **2 байта** (кнопка + состояние)
- Задержка: **< 1 мс** в локальной сети
- Поддерживаются: **ЛКМ (button=0)** и **ПКМ (button=1)**

## 🔗 Полезные команды

**Узнать IP второго ПК:**
```cmd
ipconfig
# Ищите "IPv4 Address"
```

**Проверить связь:**
```cmd
ping 192.168.1.100
```

**Остановить сервер кликов:**
- На ПК1: `Ctrl+C` в консоли
- На ПК2: закрыть чит
