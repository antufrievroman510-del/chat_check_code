  Инструкция по установке и использованию
================================================================================

НАЗНАЧЕНИЕ:
-----------
Эта программа перехватывает нажатия кнопок мыши (ЛКМ/ПКМ) на игровом ПК
и отправляет их по сети на второй ПК, где запущен чит с Makcu платой.

Движения мыши обрабатываются отдельно через Makcu плату (COM-порт),
а эта программа отвечает ТОЛЬКО за передачу нажатий кнопок.


ТРЕБОВАНИЯ:
-----------
1. Windows 10/11
2. Visual Studio с компонентом "C++ Desktop Development" (для компилятора cl.exe)
3. Оба ПК должны быть в одной локальной сети (WiFi или роутер)
4. Права администратора для запуска программы


УСТАНОВКА:
----------

ШАГ 1: Компиляция
-----------------
1. Откройте "Developer Command Prompt for Visual Studio"
   (Пуск -> Поиск -> "Developer Command Prompt")

2. Перейдите в папку с программой:
   cd C:\PWNZ AI\PC1_MouseSender

3. Запустите сборку:
   build.bat

   ИЛИ вручную:
   cl /EHsc /O2 MouseSender.cpp Ws2_32.lib /Fe:MouseSender.exe

4. После успешной компиляции появится файл MouseSender.exe


ШАГ 2: Настройка
----------------
1. Откройте файл config.txt в любом текстовом редакторе

2. Укажите IP-адрес второго ПК (читового):
   IP=192.168.1.100
   
   Как узнать IP второго ПК:
   - На втором ПК откройте командную строку
   - Введите: ipconfig
   - Найдите строку "IPv4 Address" в разделе вашего подключения
   - Скопируйте это значение в config.txt

3. Порт оставьте по умолчанию (5556), если не меняли в чите


ШАГ 3: Настройка второго ПК (читового)
--------------------------------------
1. Откройте брандмауэр Windows на втором ПК

2. Создайте правило для входящих подключений:
   - Тип: UDP
   - Порт: 5556
   - Разрешить подключение

   ИЛИ выполните команду от имени администратора:
   netsh advfirewall firewall add rule name="PWNZ AI Clicks" dir=in action=allow protocol=UDP localport=5556

3. Убедитесь, что чит запущен и сервер кликов активен


ЗАПУСК:
-------
1. На втором ПК (читовом) запустите чит
   - Сервер кликов запустится автоматически

2. На первом ПК (игровом):
   - Щелкните правой кнопкой мыши на MouseSender.exe
   - Выберите "Запуск от имени администратора"
   
   ВАЖНО: Программа требует прав администратора для установки глобального хука!

3. Программа покажет сообщение об успешном подключении

4. Теперь при нажатии ЛКМ/ПКМ на игровом ПК, нажатия будут передаваться на читовый ПК


ПРОВЕРКА РАБОТЫ:
----------------
1. Запустите MouseSender.exe на ПК1
2. Нажмите ЛКМ или ПКМ
3. В консоли должны появиться сообщения:
   [CLICK] ЛКМ НАЖАТА
   [CLICK] ЛКМ ОТПУЩЕНА

4. На втором ПК чит должен эмулировать эти нажатия


УСТРАНЕНИЕ НЕПОЛАДОК:
---------------------

Проблема: "Не удалось установить хук!"
Решение: Запустите программу от имени администратора

Проблема: "Ошибка отправки, попытка переподключения..."
Решение: 
  - Проверьте, что второй ПК включен и в сети
  - Проверьте правильность IP в config.txt
  - Проверьте, что порт 5556 открыт в брандмауэре второго ПК
  - Убедитесь, что чит запущен на втором ПК

Проблема: Клики не передаются
Решение:
  - Проверьте, что оба ПК в одной сети
  - Попробуйте пропинговать второй ПК: ping 192.168.1.100
  - Временно отключите антивирус/брандмауэр для проверки


БЕЗОПАСНОСТЬ:
-------------
- Программа работает как отдельный процесс, не внедряется в игру
- Античит не видит связь между игрой и этой программой
- Сетевое соединение идет от процесса чита, а не от игры
- Используется UDP протокол с минимальной задержкой


ОСТАНОВКА:
----------
Нажмите Ctrl+C в окне программы или закройте его


ТЕХНИЧЕСКИЕ ДЕТАЛИ:
-------------------
- Протокол: UDP
- Порт: 5556
- Формат пакета: 2 байта (кнопка + состояние)
- Задержка: < 1 мс в локальной сети
- Перехват: Global Low-Level Mouse Hook (WH_MOUSE_LL)
